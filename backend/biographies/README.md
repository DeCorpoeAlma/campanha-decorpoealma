## 🎯 Finalidade

Estas biografias servem como:

1. **Base de conhecimento** para o chatbot da campanha
2. **Referência** para materiais de comunicação
3. **Arquivo** oficial das informações dos candidatos
4. **Fonte** para respostas automatizadas sobre candidatos

## 📝 Formato

Todas as biografias seguem um formato estruturado com:
- **Dados pessoais**
- **Formação académica**
- **Experiência profissional**
- **Cargos políticos/associativos**
- **Áreas de especialização**
- **Filosofia/citação pessoal**

## 🔄 Manutenção

Para manter as informações atualizadas:
1. Editar diretamente os ficheiros Markdown
2. Atualizar o `candidate_knowledge.py` se necessário
3. Reiniciar o chatbot para aplicar mudanças

## 🤖 Integração com Chatbot

Estas biografias são integradas no chatbot através do módulo `candidate_knowledge.py`, permitindo respostas detalhadas sobre qualquer candidato da campanha.
